# Completed paper22 experiment evidence

This is the report-ready snapshot of `artifacts/paper22-final`, generated on
November 10, 2026. Read `REPORT_EVIDENCE.md` and `run.json` first. The snapshot
contains actual measured outputs, not the paper's reported numbers or legacy
notebook outputs. It includes the complete search/evaluation/ablation/XAI data.

The fitted `model.joblib` is intentionally omitted from Git. It remains in the
local original run directory and can be regenerated using the commands in the
repository README. The snapshot has its own SHA256 manifest for the files it
actually contains. `.gitattributes` preserves these generated bytes across Git
checkouts so text newline conversion does not invalidate the hashes.

Selected model: tuned Random Forest, selected using validation macro F1 before
test evaluation. Test accuracy: 329/330 = 0.996969696969697. LIME's sampled local
surrogate has R2 about 0.276: report that fidelity limitation explicitly.

No historical yield prediction, field trial, actual cloud upload or cloud
deployment is established by this evidence. See `docs/VALIDATION.md` and
`docs/PAPER_IMPLEMENTATION.md` in the repository for the full limitations.
